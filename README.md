# FATIRLOGIST

Проект для управления каталогом товаров и покупателей в Google Sheets.

## Структура
- Google Sheet: FATIRLOGIST
- Колонки: Артикул, Название товара, Имя покупателя, Поле 4-9
- Интеграция с Telegram-ботом и n81-next дашбордом
